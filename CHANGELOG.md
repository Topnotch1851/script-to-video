# Changelog

## 1.1.0 — 2026-10-22
- The master prompt is now built into the skill as its architect (`references/architect.md`); no prompt to paste.
  Give it a topic or a script.
- Topic-only requests: web research, a script with sources, and script approval before planning.
- Quality menu with live prices for every level: Nano Banana 2 or Nano Banana Pro pictures, MiniMax H3 or
  Kling 2.6 Pro animation, for still and animated videos.
- Director mode: a pasted production prompt keeps its scene, clip and line wording word for word.
- Make-your-own-pictures prompts are exactly the prompts the skill would use (same words, references, order, shape).
- Chained shots (each clip runs from one picture to the next), long lines over two pictures (`continues`),
  Kling settings (5/10 s, negative prompt, no generated audio).
- Separate sound tracks for CapCut; music default -10 dB under the voice, dipping 4 dB.
- Lessons from three real episodes made for $0.47-$0.96 each.

## 1.0.0 — 2026-10-20
First public release.
- Skill + Claude Code plugin + master prompt.
- Intake: length, vertical/landscape/square, 13 styles, still/animated/mixed, pictures made here or by you,
  presenter, voice, music, on-screen text (none, subtitles, key words, teaching).
- Live price quotes with spending caps; approval gates before every paid step.
- Bring-your-own pictures: per-picture prompt pack, layout guide, Google Drive or attachments, automatic checks.
- Local, free assembly: smooth camera moves on stills, timed text, sound effects, clip ambience, ducked music,
  −16 LUFS loudness, captions (.srt), YouTube chapters, thumbnails, packaging.
- Own footage and own voice recordings supported (split one recording into lines automatically).
- Start from just a topic: the skill asks the creative questions and writes the script and a full production brief
  (angle, cast, locations, every scene, voices, sound, cost) that can be saved and reused ("another one like this").
- Casts of 2–4 characters with one cast sheet, location reference pictures, cutaways, per-scene reference routing.
- Dialogue: several voices per scene, placed one after another automatically; speaker names in the .srt.
- Free (non-looping) acting clips up to 15 s; bold yellow TV subtitle look.
