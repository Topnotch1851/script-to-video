# Animation prompts — One key for every lock

For any image-to-video tool. Use the picture as the FIRST frame. For beats marked *loop*, also use the SAME picture as the LAST frame (the clip loops cleanly and characters stay on-model). Beats marked *free* have no last frame.

### 01.mp4 (first frame 01.png, 7 s, free: no last frame)

```
Rita peels sticky notes off her arms one by one, more fall from the wall, Max sighs. Mostly locked camera. Characters act with their whole bodies; their designs, faces, clothes and colours never change. No new characters, no text appears.
```
